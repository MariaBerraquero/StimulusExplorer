Rotating Snakes
Kitaoka's illusion — a static image with asymmetric luminance sequences that triggers illusory motion perception.

About

A completely static image — no physical motion. The asymmetric luminance sequence (black → dark grey → white → light grey) triggers illusory rotation. Illusory motion follows the B → D → W → L direction within each ring.
